# Закрывающий тег

Финальный проект модулей вёрстки в Яндекс Практикуме: страница-рефлексия о пройденном пути на курсе.

## Что сделано

- Вариативный шрифт Inter (веса 400–785, настройки через `font-variation-settings`) и акцентный PressStart2P.
- Фиксированный фон из трёх градиентов: сетка из полос и затемнение сверху вниз.
- Восемь карточек с лейблами (`mix-blend-mode: hard-light`, `-webkit-text-stroke` с проверкой через `@supports` и фоллбэком `text-shadow`) и разными CSS-фильтрами картинок.
- Кнопки с анимацией заливки псевдоэлементом и перекраской текста через `mix-blend-mode: difference`.
- Анимированная иконка сердца: наведение, нажатие, лайк с масштабированием и вспышкой искр.
- Модальное окно на элементе `dialog` с фоном через `::backdrop`.
- Адаптив до 320 px, отдельные правила для экранов до 375 px.
